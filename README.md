# Luis Mario Agreda Portfolio

Personal portfolio and resume site built with Astro, React, and TailwindCSS.

## Getting Started

Clone Repository
```sh
git clone https://github.com/lmdevv/luis-mario-portfolio.git
```

Install Dependencies
```sh
pnpm install
```

Development
```sh
pnpm run dev
```

Build
```sh
pnpm run build
```

Preview
```sh
pnpm run preview
```
